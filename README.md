# MikaFlow Releases

This public repository contains Windows binary releases and end-user documentation for MikaFlow. The MikaFlow application source repository remains private.

MikaFlow is a local-first image workflow with five included sections enabled by default:

- Home
- Studio
- Prompts
- Archive
- Tools

Notes, Pixiv Stats, Assistant, and Shop are optional and remain disabled until enabled from the collapsed Additional features group in Settings.

## Download

Open [Releases](../../releases/latest), download the unsigned `win-x64` installer and its `SHA256SUMS.txt`, verify the checksum, and follow the installation wizard.

MikaFlow currently has no Authenticode signature, so Windows Defender SmartScreen can show an unknown-publisher warning. Download only from this repository and verify the SHA-256 checksum before running it.

The package is self-contained for 64-bit Windows 10 version 1809 or later. A separate .NET installation is not required.

Read `PRIVACY.md`, `APPLICATION-LICENSE.md`, and `THIRD-PARTY-NOTICES.md` before distribution or use.
